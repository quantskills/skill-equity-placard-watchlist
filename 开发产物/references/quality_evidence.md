# 质量证据 · skill-equity-placard-watchlist（#17）

> 本文件记录：参数整定、测试覆盖、开发中**实测复现并修复的假阳性**、以及需要如实转达的边界。
> 所有数字均由真实 PandaData 调用得到，可复现。**非验收门槛、非投资建议。**

## 一、参数整定

| 参数 | 值 | 含义 | 依据 |
|---|---|---|---|
| `lines` | 5/10/15/20/25/30 | 法定披露梯度 | 《证券法》首次 5%、其后每 5% |
| `control_line` | 30 | 控制权线 | 要约收购/豁免分水岭 |
| `approach_band` | 1.0 | 逼近预警带（个百分点） | 一个季度内买 1% 是常见量级 |
| `lock_months` | 6 | 短线交易归入权锁定期 | 《证券法》第 44 条 |
| `min_pct_move` | 0.01 | 噪声下限（个百分点） | 小于此为小数精度漂移 |
| `strategic_jump` | 3.0 | 战略意图的单期增持门槛 | 一次加 3 个点不像财务投资 |
| `cap_min_holders` | 3 | 推断股本变动所需最少股东数 | 少于 3 人无法区分"共同缩放"与"巧合" |
| `cap_consensus` | 0.6 | 比值需聚在中位数附近的比例 | 允许少数人同时真交易 |
| `cap_tol` | 0.01 | 「聚在附近」的相对容差 | ±1%，覆盖四舍五入误差 |
| `cap_min_dev` | 0.005 | 认定股本变动的最小偏离 | 中位比值偏离 1 超 0.5% 才认 |

## 二、开发中实测复现并修复的假阳性

### ✅ 假阳性 1【口径错误】`flow` 行的 `hold_percent_total` 不是占总股本比例

- **现象**：`get_top_holders` 不指定 `stock_type` 时同时返回 `total` / `flow` 两套行，
  两者的 `hold_percent_total` **字段名相同但含义不同**。
- **实证**：格力电器持盾安环境 002011.SZ @20241231 —— `flow` 行读 **25.38%**、`total` 行读 **38.46%**。
  格力 2021 年收购约 38% 是公开事实，故 `total` 为真、`flow` 行该字段是在流通股本上算的。
- **后果（若不修）**：举牌梯度系统性偏低——38% 的控股级持股会被读成 25%，跨 25%/30% 的关键判定全错。
- **修复**：`normalize_holders` 强制 `stock_type == 'total'`。
- **回归**：`test_total_vs_flow_caliber`（同时喂两套行，断言只留 total 且值为 38.46）。

### ✅ 假阳性 2【最大来源·通道账户】北向托管/回购专户不是举牌人

- **现象**：全市场扫描"上穿 5%"事件，**前 12 条里 8 条是「香港中央结算有限公司」**——
  那是沪深股通的名义持有人（北向托管），背后是成千上万境外投资者，**没有任何人交过权益变动报告书**；
  另有「回购专用证券账户」——公司自己回购。
- **修复**：`classify_holder` 按主体名归类（北向托管 / 回购专户 / 国家队 / 结算登记 / 举牌人），
  通道类**默认剔除但单独成 `channel_flow` 表**——北向持股穿越 5% 本身是有信息量的资金信号，只是不叫举牌。
- **回归**：`test_channel_account_excluded`（真举牌 1 起进主表、2 起通道进副表、副表文案含"不构成举牌"）。

### ✅ 假阳性 3【最严重·股本稀释】增发不是减持

- **现象**：首轮全市场扫描得 **减持跌破 1923 起 vs 首次举牌 42 起（45:1）**，比例明显不合常理。
- **实证复现**：

  ```
  301629.SZ @20250324   七个股东同时"跌破"
    何沁修 / 杨波 / 王胜利 / 胡泓 / 辜国文   12.2198% → 9.1648%   比值 0.75000
    深圳市西博壹号自控设备创投合伙企业        6.0610% → 4.5457%   比值 0.75000
    宁波梅山保税港区丰年君和投资合伙企业      5.4849% → 4.1137%   比值 0.75001
                                                       ↑ 全是 0.75 = 发行 1/3 新股
  600358.SH @20260717   六个股东全部 ×0.4341（发行股份购买资产，总股本涨到 2.3 倍）
    江西省旅游集团股份有限公司  19.5674% → 8.4944%  ← 若不处理会被报成特大减持，实际一股没卖
  ```

  全市场量化：**991 个 (票,报告期) 组合存在股本变动**（占全部组合 4.6%），
  最高频比值 `0.7500` 出现 48 次、`0.9000` 出现 13 次——典型的新股发行与增发比例。

- **后果（若不修）**：17.9% 的事件是假的；而且"江西省旅游 19.57%→8.49%"这种会排在结果最前面，
  是最显眼的错误。
- **反向同样危险**：回购注销使总股本缩小，所有人比例被动**升破** 5%——那不是举牌（没人买过一股）。
- **修复**：
  1. `infer_share_change()` 按 (票, 报告期) 取比值中位数为 `k`，需 **≥3 个股东**且 **≥60% 聚在 ±1% 内**
     才敢认定（比值不齐 → 不是统一缩放，宁可不调也不乱调）；
  2. `base_pct = prev_pct × k` 即"完全不交易应有的比例"；
  3. **越线判定 = 实际越线（prev→cur） − 被动越线（prev→base）**，只认交易造成的穿越；
  4. `active_delta = pct − base_pct` 近似 0 时直接不出事件（纯被动）。
- **中途走过的弯路（如实记录）**：初版把越线基准整个换成 `base_pct`，导致 `placard` 从 42 涨到 160
  ——那是**过度检出**：举牌线是按实际持股比例画的，基准不该改。改为"实际越线减去被动越线"后回到正确口径。
- **效果**：同一口径（均已剔除通道账户）对比：

  | | 首次举牌 | 继续加码 | 减持跌破 |
  |---|---|---|---|
  | 无稀释校正 | 42 | 203 | 1923 |
  | **有稀释校正** | **37** | **188** | **1556** |

  剔除 **387 条假事件（17.9%）**，两个被证伪案例（600358 / 301629）均已剔除，
  两个真举牌（601005 华宝投资 1.55%→9.31%、002825 章建良 4.878%→5.003%）均保留。
- **回归**：5 项 —— `test_share_change_inferred`（k=0.75 推断正确）、
  `test_passive_dilution_not_reported`（对照组误报 5 条 → 校正后 0 条）、
  `test_active_sale_during_dilution_kept`（稀释期间真卖家仍检出，其余 4 人静音）、
  `test_buyback_cancel_passive_rise_not_placard`（缩股被动升破，对照组误报 4 起 → 0 起）、
  `test_dilution_needs_consensus`（单人变动不误判为股本变动）。

### ✅ 缺陷 4【落盘】审计字段缺失 + 主键漏项

- **现象**：首版 `_RESULT_COLS` 未包含 `base_pct` / `active_delta` / `share_change_k` / `change_kind`
  ——稀释校正的**判定依据无法追溯**；且主键漏了 `as_of_date`，实测 **1781 条落盘后只剩 1769 条**
  （同一公告日的多个报告期事件互相覆盖，丢失 12 条）。
- **修复**：审计字段全部落盘成列（Alpha/agent 不必解 `result_json` 即可用）；主键补 `as_of_date`。
- **回归**：`test_output_schema` 断言主键含 `as_of_date` 且四个审计字段必须在列。

### ✅ 缺陷 5【静默截断】看板表格默认 `.head(40)` 却不声明

- **现象**：`render_html` 的通道账户表写死 `.head(40)`，超出部分**静默丢弃**——
  读者会以为看到了全部。
- **修复**：抽出 `_cap_note()`，超量时显式提示"共 N 条，本表仅显示前 M 条，完整数据见 database.parquet"；
  同时把举牌/加码排到减持之前（本 skill 的主角优先展示）。

> 而真金白银买上 5% 的新举牌方本就稀少。已在 README / 生产 SKILL.md 说明。

## 五、需要如实转达的边界

1. **报告期快照口径，非实时播报** —— 只能看到报告期截面，报告期之间发生并回撤的举牌**看不到**。
   这是数据可得性的天花板（PandaData 无举牌事件表），不是实现偷懒。
2. **一致行动人无法合并** —— 数据无该字段。多个关联方各持 4%、合计超 5% 的情形**检测不到**，
   而这恰恰是现实中举牌方常用的隐蔽手法。这是本 skill 最实质的盲区。
3. **仅十大股东** —— 5% 持股几乎必进前十，但理论盲区存在。
4. **`intent` 是先验倾向不是定论** —— 数据无"举牌目的"字段，只能依据主体性质 / 持股高度 / 增持力度推测。
   agent 引用时必须保留"倾向"措辞，不得说成"该方意在夺取控制权"。
5. **股本变动校正需 ≥3 个股东** —— 2 人以下的小样本组合不做校正，可能残留少量稀释假阳性。
6. **举牌 ≠ 会涨** —— 本工具只检出事件，不预测标的表现，不构成投资建议。
